# Living the Simple Life

A responsive multi-page blog website about minimalism, built with HTML and CSS.

**[Live Demo](https://jana-alhasan.github.io/Living-the-Simple-Life/)**

## About the Project

This project was built as part of the Responsive Design module of the Scrimba Front-End Career Path. The goal was to practice HTML and CSS and to apply responsive design techniques so the layout adapts to desktop, tablet, and mobile screens.

The site is a mock blog, so some links (such as "Continue reading") are placeholders.

## Pages

- **Home** (`index.html`): featured article, recent articles, and a sidebar
- **About me** (`about-me.html`)
- **Recent posts** (`recent-posts.html`)

## What I Practiced

- Responsive layout with media queries and flexible units
- Flexbox for page and component layout
- Semantic HTML (`header`, `nav`, `main`, `article`, `aside`, `footer`)
- Organizing CSS for a multi-page site

## Technologies

- HTML5
- CSS3

## Run Locally

```bash
git clone https://github.com/jana-alhasan/Living-the-Simple-Life.git
cd Living-the-Simple-Life
```

Then open `index.html` in your browser.
